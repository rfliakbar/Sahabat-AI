Koneksi Sistem Gudang & Kasir (POS)

Kode ini sudah dilengkapi protokol komunikasi dua arah agar aplikasi Kasir (POS) langsung menerima produk baru dan mengirim pengurangan stok.

1. Data Produk Terpusat (Master Schema)

Format JSON yang otomatis dikirim ke Katalog Visual Kasir

{
  "id": "PRD-1732271001",
  "sku": "BNH-PADI-01",
  "name": "Benih Padi Unggul Inpari 32 (5kg)",
  "price": 75000,
  "image": "data:image/jpeg;base64,...",
  "warehouseStock": 120,
  "shelfMax": 20,
  "shelfMin": 5,
  "shelfCurrent": 18,
  "updatedAt": "2026-11-22T18:42:00Z"
}

2. Event Sinkronisasi Kasir → Gudang

Cara sistem kasir mengurangi stok gudang & display rak

Aplikasi ini membuka saluran BroadcastChannel('agristock_pos_sync') serta menyediakan fungsi global window.AgriStockBridge.recordPosSale(sku, qty). 

// Contoh kode di Aplikasi Kasir saat pembayaran sukses:
const posChannel = new BroadcastChannel('agristock_pos_sync');
posChannel.postMessage({
  type: 'POS_SALE_COMPLETED',
  items: [
    { sku: 'BNH-PADI-01', qty: 3 }
  ]
});
