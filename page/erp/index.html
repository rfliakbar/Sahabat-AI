Catatan Metodologi

  • Pendapatan = total transaksi termasuk PPN 11%.
  • HPP = harga pokok penjualan dari setiap item terjual (modal × kuantitas).
  • Laba kotor = subtotal − diskon − HPP. Laba bersih = laba kotor − biaya pembayaran − biaya operasional.
  • Data bersumber dari modul Kasir (transaksi) dan Gudang (penerimaan barang), disinkronkan real-time.

Mode offline menggunakan mesin analitik deterministik pada data ERP Anda — tidak mengirim data ke mana pun. Untuk insight naratif lebih kaya, hubungkan API AI (OpenAI/OpenRouter/Groq/Ollama) di menu Pengaturan & AI. Data hanya dikirim saat Anda menekan tombol analisis.
